* markdown-it layer

This layer configures =markdown-mode= (provided by the built-in =markdown=
layer) to render previews with the Node [[https://github.com/markdown-it/markdown-it][markdown-it]] library — the same engine
VS Code's markdown preview uses.

** Prerequisites

Install the Node packages globally:

#+begin_src sh
npm install -g markdown-it highlight.js
#+end_src

** What it does

- Sets =markdown-command= to =env NODE_PATH=$(npm root -g) node <layer>/render.cjs=
- =render.cjs= reads markdown on stdin and writes an HTML fragment to stdout,
  replicating VS Code's =markdownEngine.ts=:
  - markdown-it with =html=, =linkify=, =typographer=
  - highlight.js for fenced code blocks
  - =data-line= / =code-line= source-map attributes
  - slugified heading =id=s
  - =hljs= class on =<pre>=
  - VS Code's language quirks (=shell=→=sh=, =tsx=→=jsx=, =c#=→=cs=, …)
- =markdown-command-needs-filename= is =nil=, so previews work on unsaved buffers.
- Mermaid diagrams: =```mermaid= fences are emitted as =<pre class="mermaid">=
  and rendered to SVG in the browser by mermaid.js (loaded from CDN in the
  preview header, like the stylesheets)

** Mermaid diagrams

Fenced blocks tagged =mermaid= are not highlighted by highlight.js; instead
the diagram source is emitted directly inside a =<pre class="mermaid">= block
(no =<code>= wrapper) and rendered client-side by
[[https://mermaid.js.org/][mermaid.js]], which the layer loads from =jsDelivr=
(v11) in the preview header — the same strategy VS Code's markdown preview
uses. The =<code>= wrapper is deliberately omitted because mermaid ≥ 11 reads
the diagram source from =element.innerHTML=, so a wrapper tag would be fed to
the parser and fail with =Syntax error in text=. The diagram theme follows the
system color scheme (=default= light, =dark= in dark mode), matching the
Water.css setup.

Rendering happens in the browser, so previews need internet access at preview
time to load mermaid.js from the CDN.

** Styling

No CSS is wired by default. Set your own via =markdown-css-paths=, or use the
helper:

#+begin_src elisp
M-x markdown-it/set-css
#+end_src

** Usage

- =markdown-preview= (=SPC m c p=) — render and open in browser
- =markdown-export= (=SPC m c e=) — write =.html= next to the =.md=
